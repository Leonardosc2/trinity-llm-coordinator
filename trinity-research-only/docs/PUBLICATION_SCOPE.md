# Research-only publication scope

## Included material

This package is built from an explicit allowlist of Markdown documentation, selected Python research functions, synthetic tests, aggregate result counts, a minimal dependency declaration, and release-validation information.

## Excluded material

The public-facing package intentionally excludes:

- Personal names, contact details, account handles, employer and institution identifiers.
- Hostnames, IP addresses, ports, network endpoints, login portals, and server or workstation specifications.
- Original absolute filesystem paths, personalized workspace names, deployment commands, and access configuration.
- Credentials, environment files, private keys, private links, connection-oriented API clients, and authentication logic.
- Raw logs, raw prompts or model outputs, dataset rows, held-out question identifiers, answers, and item-level review notes.
- Original archives, screenshots, binary checkpoints, optimizer state, model weights, and prior repository history.

Aggregate counts and research model names remain because they describe the experiments without specifying access to any system. The only hidden file is a newly prepared generic ignore file. Archive entries have generic filenames and normalized timestamps; no original archive comments or extra fields are copied.

## Review boundary

Only this package is covered by its validation record. Earlier ZIPs, previous repository commits, shared messages, and original attachments are not modified or deleted by preparing it. Do not merge old archives or operational notes back into this release.

The content was intentionally minimized, checked for known identifiers and common secret/address patterns, and reviewed as text. Pattern scans cannot prove that every possible confidential fact has been recognized. Publication rights to research and source code remain a separate decision.

No original confidential values are repeated in this review document. The source archives are not bundled as backups. This package has not itself been uploaded to an external repository.
